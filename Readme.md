# Keep Smiling, My Sunflower

A single-page message under a clear night sky: two silhouettes sitting on a
hill, stars twinkling overhead, an occasional shooting star, and the words
above them.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## The song

Put your copy of *Khat* at `assets/khat.mp3`. It fades in on the first tap
anywhere on the page and loops. The corner button plays and pauses it. Without
that file the page still works; only the music is missing.

## Files

- `index.html` — the whole page, self-contained apart from the font and the song
- `assets/` — where the music file goes
